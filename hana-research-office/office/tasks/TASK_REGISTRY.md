## 오늘 수행 대상 — 편성 규칙 (2026-09-23 개편)

관리 페이지의 "오늘" 탭은 **선별형**이다. 상시 업무가 매일 전부 올라오면 그날 다 해야 하는 것처럼 보이므로, 아래 규칙으로 운영한다.

| 구분 | 오늘 목록 편입 방식 |
|---|---|
| Daily · 상시 | **자동 편입하지 않음.** 그날 발생한 건만 ＋ 버튼으로 직접 올린다 |
| Weekly | 지정 요일(`dow`)이 오늘이면 자동 편입 |
| Monthly | 지정 날짜(`mday`) 또는 기간(`mfrom`~`mto`)에 해당하면 자동 편입 |
| 단발 업무 | 자동 편입하지 않음. ＋ 버튼으로 직접 올린다 |

- **× 버튼**으로 오늘 목록에서 내리면 그날은 제외된다(다음 날 다시 판단).
- 자동 편성은 **평일 06:03(KST)** 에 Routine이 수행한다 (`trig_01LKYqgnzXrL5Lh3Yp7At5Jv`). 이미 그날 목록이 있으면 덮어쓰지 않는다.
- Routine이 돌지 않아도 페이지를 처음 열 때 자동 편성되므로 목록이 비는 일은 없다.

## 업무 직접 편집

업무 정의는 아티팩트 DB(`tasks` 컬렉션)에 저장되어 있어, 관리 페이지에서 직접 추가·수정·삭제할 수 있다.
- 추가: 각 구역의 **＋ 업무 추가** 버튼
- 수정·삭제: 업무 상세 → **업무 수정**
- 사장이 인수인계서를 받아 상세를 채울 때도 같은 DB에 기록하므로, 페이지 재발행 없이 즉시 반영된다.

## 관찰 사항 (사장 메모)

1. **복지카드 QR 신청은 지금 진행 가능** — 선행 조건인 하나카드 발급이 완료 처리되어 있음.
2. **작업 통합 가능성** — 「국가별 전기차 판매량」(월)과 운용사 3곳 정기리퀘스트의 전기차 판매대수가 동일 원천일 가능성. 확인되면 1회 집계로 4건을 처리할 수 있음.
3. **양극재 수출량(1일) vs 지역별 양극재 수출량(15일)** — 동일 원천의 지역 분해 버전으로 추정. 확인 시 한 번의 수집으로 두 건 처리 가능.
4. **광물가격 주간 갱신 → 월평균 산출** 체인이 확인됨. 주간 갱신분이 누적되면 월말 작업이 자동화 대상이 됨.
5. **발간 프로세스 7단계가 누락 위험 최대** — 관리 페이지에서 단계별 체크 기능으로 구성함.
