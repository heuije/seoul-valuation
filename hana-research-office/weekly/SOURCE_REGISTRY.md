# 소스 등록부 (작성 대기)

> 대표이사 제공 자료를 근거로 작성한다. 아래 표만 채워지면 트랙 배정과 파이프라인 구축이 가능하다.
> 편하신 형식(메모, 엑셀, 캡처)으로 주셔도 되며, 조직이 이 표로 정리한다.

| # | 지표명 | 단위·기준 | 출처 기관 | 소스 위치(URL/DB/파일) | 갱신 주기 | 보고서 내 위치 | 트랙 |
|---|---|---|---|---|---|---|---|
| 1 | | | | | | | A/B |
| 2 | | | | | | | A/B |

## 항목 설명

- **단위·기준**: 달러/톤, 원/kg, %, 연결/별도 등. 기관별 집계 기준이 다르면 함께 기재.
- **소스 위치**: 공개 URL / 유료 DB명 / 사내 시스템 / 수기 관리 엑셀 등.
- **보고서 내 위치**: 해당 지표가 보고서의 어느 표·그래프에 들어가는지.
- **트랙**: A = 웹 자동 수집 가능, B = 수기 입력 필요. 접근 가능 여부는 조직이 실측 후 확정한다.

## 접근성 실측 결과 (자료 접수 후 기록)

| 소스 | 접근 가능 여부 | 확인 방법 | 조치 |
|---|---|---|---|
| | | | |

> 접근 불가 소스 중 필요한 것은 환경 네트워크 정책(Custom 허용 도메인) 등록으로 열 수 있다. 등록 후에도 로그인·구독이 필요한 소스는 트랙 B로 확정한다.
